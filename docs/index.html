A barbell log you keep.

Rampset is a free, open-source strength log for 5×5, Madcow, or a routine you write yourself. It lives on your phone, works with no signal, and signs you in with Face ID or a fingerprint.

Put it on your home screen

Rampset is a web app you install from the browser, so there's no app store. The public copy at liftlog.zackdesign.biz is open to anyone: create an account with a passkey, then add it to your home screen and it opens full screen like any other app, offline included.

iPhone or iPad

  1. Open liftlog.zackdesign.biz in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open Rampset from the new icon and tap Create account.

Android

  1. Open liftlog.zackdesign.biz in Chrome.
  2. Tap the ⋮ menu, then Add to Home screen or Install app.
  3. Open Rampset from the new icon and tap Create account.

What it does

Everything below is from the current app, on an iPhone-sized screen, with a few weeks of training logged.

Tap a set when you rack the bar

Each work set is a circle. Tap it once for all five reps; tap again to count down a missed rep. The circle takes the colour of the biggest plate on the bar, so you can check you've loaded red 25s from across the room.

  • The rest timer starts by itself and rings when it's time to go again.
  • A warm-up tab ramps you up from the empty bar, with plates per side worked out.
  • Hit every rep and the weight goes up next time. Stall three times and it backs off 10%.
  • The screen stays awake for the whole workout.

See every session, and how far you've come

History is a calendar of every workout with a recap of what you lifted. Progress charts each lift's top set, estimated one-rep max, volume and reps, alongside your body weight.

  • A gold star marks a new personal record the moment you set it.
  • Got a number wrong? Open the workout and fix it. The correction reaches your other devices too.

Pick a program, or write your own

You choose when you sign up and can switch any time in Settings. Your history and working weights come with you.

StrongLifts-style 5×5

For starting out

Workouts A and B alternate, squat every session, and weight goes up every time you get all your reps. Variants included: Plus, Lite, Mini, Ultra, Ultra Max and Intermediate.

Madcow 5×5

When linear gains slow down

Heavy, light and intensity days. Sets ramp up to a top set, and Friday's top set decides next week's weights, so you progress weekly instead of every session.

Custom routine

Your own split

Add, rename, reorder and delete days; add exercises, change their sets, reps and rest, and move them around. Nothing is prescribed: every set fills in from what you did last time.

A routine built in the app

This one is a three-day push, pull and legs split, made in the Program tab. On the day, each row already holds last session's weight and reps; change what you need and tick it off.

Dark or light is a setting per account. The custom routine above is shown in light.

Your data comes and goes with you

Every workout is stored on your phone first. Settings → Your data is where it moves in and out.

  • Import your history from a StrongLifts or Strong export.
  • Download a backup of everything (programs, weights, history) and restore it on any phone or into any account.
  • Export CSV for a spreadsheet.
  • Cloud backup runs after every workout, and you can restore from it.
  • Sync keeps your phone and tablet in step.

How it works

Rampset is a Next.js app running on Cloudflare Workers. What matters is what happens on your phone and how it signs you in.

Offline first

The phone's own database (IndexedDB) is the source of truth. A whole workout works with no connection at all, in a basement gym or on a plane, and uploads when you're back online.

Sync between devices

Each account has its own Durable Object that puts every change in order, using the open-source durable-sync library. A workout arrives on your other device exactly once, and if two devices correct the same workout, the later edit wins.

Passkeys, not passwords

Your phone saves a passkey, and Face ID or your fingerprint is the login. Add a recovery email and, if you lose every device, a 6-digit code gets you back in. One account per device. Sign-in is the open-source durable-auth library.

How it's tested. End-to-end journeys drive the built worker in a real browser with nothing mocked: signing up with a passkey, training 5×5, Madcow and a custom routine, correcting history, importing from StrongLifts, recovering by email, deleting an account. Sync is checked on an online, offline, flappy and slow connection. Integration tests run the Durable Objects on workerd, and more than 350 unit and component tests cover the progression engines and screens.

Run your own copy

Rampset deploys to your own Cloudflare account. Anyone can create an account on your instance. Accounts, passkeys and sync live in Durable Objects, so there's no database to set up.

  1. Clone and install. Fork the repo, then npm install. npm run preview runs the real worker locally, with Durable Objects, R2 and email.
  2. Point it at your domain. In wrangler.jsonc, change the route from liftlog.zackdesign.biz to your own domain. Passkeys are tied to that one origin.
  3. Deploy. npm run deploy builds with OpenNext and ships the worker with its two Durable Objects, AUTH and SYNC_JOURNAL.
  4. Cloud backups (optional). Create the R2 bucket that the BACKUPS binding points at. Leave the binding out and sync still works; Download backup still gives people a full file.
  5. Recovery email (optional). Onboard a domain with npx wrangler email sending enable <domain> and set EMAIL_FROM to an address on it. Without it, the app doesn't offer email recovery.
  6. Bot protection (optional). Create a Turnstile widget and set the TURNSTILE_SITE_KEY var and TURNSTILE_SECRET_KEY secret. Sign-in, email and sync routes are already rate limited.
# run the real worker locally
git clone https://github.com/isaacrowntree/rampset
cd rampset && npm install
npm run preview        # localhost:8787

# optional: cloud backups
npx wrangler r2 bucket create liftlog-backups

# ship it
npm run deploy

What it costs: Workers and Durable Objects fit in Cloudflare's free tier for a household. Backups fit easily in R2's free 10 GB, but Cloudflare asks for a payment method before it turns R2 on. You won't be charged under the free limits. The README has the details.

Built from two smaller projects

The hard parts of Rampset have been pulled out into libraries that any Cloudflare Workers app can use.

durable-sync

Rampset's offline-first sync. A per-account journal in a Durable Object orders every change, so devices that were offline catch up without duplicates.

Project pageSourceWrite-up

durable-auth

Rampset's passkey sign-in, extracted into a library: passkeys, sessions and email recovery codes, kept in a Durable Object.
